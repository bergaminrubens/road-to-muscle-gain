# road-to-muscle-gain
Dashboard interactif développé en Python pour suivre ma prise de masse, analyser mes performances en musculation et comparer les résultats prévus et réalisés. Conçu avec Pandas, Matplotlib et Streamlit.

**Objectifs du projet**

- Suivre l'évolution de mon poids et de mes entraînements.
- Comparer les charges et répétitions prévues avec celles réellement effectuées.
- Mesurer ma progression et le respect de mon programme.
- Visualiser mes performances par groupe musculaire et par exercice.

**Technologies utilisées**

- Python : programmation et analyse des données.
- Pandas : traitement des données Excel.
- Matplotlib : création des graphiques.
- Streamlit : interface interactive et publication sur le web.
- Google Drive : stockage et mise à jour des données.

**Fonctionnement**

Le dashboard comprend quatre onglets : Vue générale, Pecs / épaules, Dos / bras et Jambes.

Les utilisateurs peuvent sélectionner une période d'analyse et afficher ou masquer les courbes représentant les charges et les répétitions prévues et réalisées.

Les données proviennent d'un fichier Excel régulièrement mis à jour.

**À propos**

Ce projet a été réalisé dans le cadre de mon apprentissage de Python et de l'analyse de données, en utilisant ChatGPT comme outil d'accompagnement et de développement.
